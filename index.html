Real-Time Multi-Agent AI Framework for Auditing Smart Contract Vulnerabilities

Candidate: Muhammad Ibraheem (Sapienza Università di Roma) | Focus: Smart Contract Vulnerabilities Audit, Agentic AI, AST Analysis, AI - Human (Co-Working )

Smart contracts residing on immutable blockchains like Ethereum manage billions in digital assets, yet remain highly vulnerable to complex multi-step logical exploits. Conventional static application security testing (SAST) tools rely on rigid pattern matching, generating high false-positive rates while failing to catch context-dependent flaws.

This research proposes a real-time, multi-agent AI framework focused exclusively on smart contract security & (AI & Human) co -working. By integrating dynamic threat feeds using fine tune local LLM and real-time vulnerabilities with full-stack Abstract Syntax Tree (AST) parsing and multi-agent dialogue, the proposed framework shifts smart contract auditing from reactive post-deployment analysis to continuous proactive defence.

🎯 Research Questions

Primary Research Question

How can a real-time, multi-agent AI framework leveraging Abstract Syntax Trees (AST) and dynamic threat intelligence improve the detection of logical vulnerabilities in smart contracts compared to traditional static analysis tools?

Sub-Question 1 (Architecture & CoT)

What is the optimal multi-agent architecture (role specialization, CoT consensus) for verifying complex vulnerabilities while minimizing hallucination?

Sub-Question 2 (Live Feed & AST)

How can dynamic threat ingestion from external feeds (NVD, OSV, GHSA) be mapped to smart contract ASTs in real time to bridge the TOC/TOU gap?

Sub-Question 3 (Exploit & Benchmarking)

How does the framework's detection accuracy, execution speed, and exploit validation perform against industry benchmarks like EVMBench and SmartBugs?

⚡ The Identified Research Gap

While existing literature acknowledges the potential of Agentic AI and the severe nature of smart contract vulnerabilities, there is currently no unified framework that actively combines real-time vulnerability checking with structural code analysis using a multi-agent architecture .

Specifically, existing tools do not continuously ingest live threat intelligence from sources like the National Vulnerability Database (NVD), GitHub Security Advisories (GHSA), and Open Source Vulnerabilities (OSV) to immediately apply it to a target smart contract codebase. Most current automated auditing approaches still rely on static, fixed rules or historic datasets, creating a critical vulnerability window (Time-of-Check to Time-of-Use) against rapidly emerging zero-day logical exploits.

Normalized data is continuously injected into a dynamic Knowledge Base to eliminate the TOC/TOU vulnerability window.

CHAINTRIX Framework

CCIM Model

Anchors LLM reasoning in a deterministic Cross-Contract Interaction Model (CCIM). Validates AI assertions against caller/callee directed graphs to eliminate hallucinated access control bugs.

cAST & SoliDiffy

AST Differencing

Replaces naive chunking with syntax-aware split-then-merge algorithms. SoliDiffy captures structural modifications across Solidity contract iterations to isolate changes.

KASS (Knowledge-Augmented Attack)

Exploit Validation

Decomposes exploit generation into planning, generation, and simulated execution. Achieves >94% executable PoC generation rate to prove exploitability on-chain.

National Vulnerability Database (NVD) Formal CVEs

US government standards repository. Provides formal CVE records, CVSS severity scores, and dependency impact metrics for underlying language libraries.

GitHub Security Advisories (GHSA) Commit Fixes

Delivers commit-level patches, dependency advisory graphs, and pull request fixes for Web3 open-source repositories and Foundry/NPM packages.

Open Source Vulnerabilities (OSV) Version Ranges

Google-developed database mapping vulnerabilities directly to precise open-source package versions and commit ranges for exact AST matching.

VulnCheck Feed Zero-Day Alerts

Real-time commercial/community threat feed tracking active on-chain exploitation, weaponized PoCs, and emerging Web3 attack vectors.

Exploit-DB Exploit Payloads

Public archive of historical exploit payloads and execution patterns synthesized by Exploit Agents for local Foundry/Anvil test generation.

⚠️

Empirical Finding: Automation Bias in CTF Security Events

Observational studies during Capture-The-Flag (CTF) events revealed that participant trust in AI decreased after hands-on usage due to hallucinated conclusions and tool misuse. Verifying complex AI reasoning frequently imposed higher cognitive load than manual investigation, reinforcing the necessity for visual support tools and deterministic AST grounding.
